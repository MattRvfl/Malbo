Malbo pour Windows.

Un seul fichier Malbo.exe, autonome : le runtime .NET est inclus, il n'y a rien d'autre à installer.

Télécharger la 1.3.1 (pré-version) Dernière version stable
64 bits (x64)GratuitToutes les versions et leurs notes

Configuration requise

  • Windows 10 version 2004 ou plus récent, ou Windows 11.
  • Processeur 64 bits (x64).
  • Facultatif : un compte Spotify, PresentMon pour le compteur FPS.
  • L'exécutable n'est pas signé : Windows SmartScreen peut demander une confirmation au premier lancement.

Installation en trois étapes

  1. TéléchargezRécupérez Malbo.exe dans la dernière version publiée sur GitHub.
  2. LancezDouble-cliquez : l'île apparaît en haut de l'écran et une icône s'ajoute à la barre des tâches.
  3. Installez (facultatif)Icône de la barre des tâches › Installer Malbo sur ce PC : raccourcis Menu Démarrer et Bureau, désinstallation via les Paramètres Windows.

Mises à jour automatiques

Depuis la 1.2, Malbo se met à jour tout seul à partir des versions publiées sur GitHub.

  • Vérification au démarrage, puis toutes les 6 h.
  • Installation automatique quand l'île est au repos (désactivable dans Réglages › Mises à jour).
  • Le fichier téléchargé est vérifié par son empreinte SHA-256 avant de remplacer l'ancien.
  • Canal bêta en option, pour recevoir aussi les pré-versions.

Compiler depuis les sources

Il vous faut le SDK .NET 10. Clonez le dépôt puis compilez :

git clone https://github.com/MattRvfl/Malbo.git
cd Malbo
dotnet build -c Release
.\bin\Release\net10.0-windows10.0.22621.0\Malbo.exe

Pour produire l'exécutable autonome d'une version, lancez .\publish.ps1 : il crée Malbo.exe, à joindre à la release GitHub.

Et ensuite ?

Connecter Spotify, ajouter votre agenda, activer le compteur FPS : tout est dans le guide.
