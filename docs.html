Guide

Prendre Malbo en main.

Tout se règle dans Réglages : icône de la barre des tâches, ou roue crantée dans l'île.

RaccourcisGestesConfiguration PluginsFichiers & données

Raccourcis clavier

TouchesAction
CtrlAltIOuvrir / épingler l'île
CtrlAltHMasquer / afficher
CtrlAltEspaceLecture / pause

Gestes

  • Survol ou clic : ouvrir l'île.
  • Clic droit : menu rapide.
  • Glisser vers le haut : fermer un aperçu.
  • Clic sur une notification : ouvrir l'appli. Glisser : la supprimer.
  • Glisser-déposer un fichier : le ranger sur l'étagère.
Configuration

Connecter vos services.

Tous ces réglages sont facultatifs : Malbo fonctionne dès le premier lancement.

Spotify

Pour le bouton j'aime et l'ajout à une playlist.

  1. Créez une appli sur developer.spotify.com.
  2. Ajoutez la Redirect URI http://127.0.0.1:8898/callback.
  3. Collez le Client ID dans les Réglages, puis cliquez sur Connecter Spotify.

Agenda

Malbo lit n'importe quel agenda au format ICS.

Avec Google Agenda : Paramètres › Adresse secrète au format iCal, puis collez l'URL dans les Réglages.

Amis Steam

Renseignez votre clé API Steam et votre SteamID64 pour voir vos amis en ligne dans l'île.

Compteur FPS

Téléchargez PresentMon et indiquez son chemin dans les Réglages : les FPS s'affichent dans l'île pendant vos parties.

Écrire un plugin

Créez une bibliothèque de classes WPF qui référence Malbo.dll, implémentez IIslandPlugin, puis déposez la DLL dans %AppData%\Malbo\plugins. Elle est chargée au prochain démarrage.

// Bibliothèque de classes WPF qui référence Malbo.dll
using System.Windows;
using System.Windows.Controls;
using DynamicIsland;

public class HelloPlugin : IIslandPlugin
{
    public string Name  => "Hello";
    public string Glyph => "\uE76E";   // glyphe Segoe Fluent Icons

    public UIElement CreateView() =>
        new TextBlock { Text = "Bonjour depuis mon plugin !" };
}

Fichiers & données

Tout reste sur votre PC, dans %AppData%\Malbo.

  • settings.json : réglages et données.
  • error.log : journal d'erreurs.
  • plugins\ : vos extensions.
